# Log Pose · puesta en marcha

1. **Supabase**: crea un proyecto gratis en supabase.com → *SQL Editor* → pega `schema.sql` → *Run*.
2. **config.js**: copia la *Project URL* y la clave *publishable* (Project Settings → API) en `SUPABASE_URL` y `SUPABASE_KEY`.
3. **Publicar**: arrastra la carpeta `logpose` a https://app.netlify.com/drop (o GitHub Pages). Te da un enlace https.
4. En el móvil: abre el enlace → *Crear o unirse a una tripulación* → *Crear*. Comparte el enlace de invitación con la tripulación.
5. Cada uno: *Añadir a pantalla de inicio* para usarla como app.

Archivos: `app.js` (lógica), `style.css` (diseño), `leaders.js` (líderes; añade líneas para nuevas colecciones), `config.js`, `schema.sql`.
